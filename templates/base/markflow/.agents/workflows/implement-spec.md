# Implement Spec

Purpose. This file is the SOP to build an approved spec.
Read when. A spec is Approved and you start coding.
Do not read when. The spec is not Approved yet. Review it first.

## Steps

1. Read the spec again. Note the acceptance cases.
2. Read the related docs listed in the spec.
3. Write code in small steps. Run tests often.
4. Do not change code outside the spec scope.
5. Stop and ask when the spec and the code disagree.
