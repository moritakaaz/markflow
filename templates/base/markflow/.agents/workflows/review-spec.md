# Review Spec

Purpose. This file is the SOP to review a spec before it is built.
Read when. A spec is ready for review.
Do not read when. The spec is still a draft. Wait until it is ready.

## Steps

1. Read the spec. Check the goal is clear.
2. Check each requirement is checkable.
3. Check out of scope is written.
4. Check acceptance cases exist.
5. Run the review and list what is missing. Only the user marks a spec Approved.
6. If the user says yes, change Draft to Approved in the spec and in specs/index.md. Then coding starts with implement-spec.
