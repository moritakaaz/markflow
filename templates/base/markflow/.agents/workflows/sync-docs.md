# Sync Docs

Purpose. This file is the SOP to sync docs when code changes.
Read when. Code changed and docs may be out of date.
Do not read when. Only docs changed. That does not need a sync check.

## Steps

1. List the docs that describe the changed code.
2. Check each doc still matches the code.
3. Update the doc when it is wrong. Do not change code to match a wrong doc without a decision.
4. Update STACK.md and MCP.md when a library changed.
5. Run doctor checks when they exist.
