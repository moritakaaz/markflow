# Create Feature

Purpose. This file is the SOP to create a feature from a spec.
Read when. You start a new feature.
Do not read when. You fix a small bug. That does not need a full feature flow.

## Steps

1. Read the spec in `specs`. Check its status is Approved.
2. Read ARCHITECTURE.md and CODING_STANDARDS.md.
3. Write the code in the source folder.
4. Write tests in the test folder.
5. Run the tests. Fix failures before you move on.
6. Update TASKS.md when the feature is done.
