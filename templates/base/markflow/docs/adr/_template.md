# ADR Template

Purpose. This file is the template for a new architecture decision.
Read when. You need to record a decision that affects architecture.
Do not read when. You only fix a small bug. That does not need an ADR.

## Decision

Write the decision in one sentence.

## Context

Write why this decision was needed. Keep it short.

## Options considered

List the options you considered. One line per option.

## Outcome

Write what you picked and why. Write what you gave up.

Write Draft or Approved.
