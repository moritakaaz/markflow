# Security Policy

## How to report a problem

Do not open a public issue for a security problem. Use GitHub private vulnerability reporting for this repo. Go to the Security tab and choose Report a vulnerability.

Describe what you found. Describe how to reproduce it when you can. Tell us what versions are affected when you know them.

We will confirm the report and work on a fix. We will keep you updated when we can.

## What happens next

We will check the report first. If it is a real problem, we will fix it in private. We will then release a fix and note it in `CHANGELOG.md`. We will not share details in public until the fix is out.

Please do not share exploit details in public before a fix is ready.

## Supported versions

Markflow is early. Only the latest version on the main branch is supported for now. We will update this section when we publish versioned releases.

## Scope

This policy covers code and templates in this repo. It does not cover user projects that use Markflow. If you find a problem in a user project, report it to that project first.
