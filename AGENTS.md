# AGENTS.md

This file is for AI agents that work in this repo. Read it first.

## What this repo is

Markflow is a universal documentation-driven development system. It is for humans and AI agents. It does not build apps. It builds docs, specs, and workflows around apps.

## Start here

Read `README.md` first. Then read `docs/PRINCIPLES.md`.

Do not start coding the CLI until the methodology docs are clear. Do not invent commands that are not in the docs.

## House rules

Use English in all docs and code. Use English in file and folder names too.

Write short sentences. Write like you talk to a teammate. Avoid em dashes. Avoid colons in prose. Avoid formal and cliché words. Avoid words like delve, leverage, seamless, robust, and cutting edge.

Keep commits small. One logical change per commit. Use the imperative mood. Keep the subject short and clear. Good examples are Add README and Fix typo in PRINCIPLES.

Do not invent architecture or decisions. If you do not know something, mark it as TBD and ask. Do not overwrite user files without approval. Do not change code outside the scope of your task.

Every doc file should start with a short note on what it is for and when to read it. Keep the README short. Put details in `docs`.

Use kebab-case for file names.

## How to work

Pick one small task. Read the relevant doc first. Make the change. Test it when there is a test to run. Show evidence before you say it is done.

If docs and code disagree, stop and ask. Markdown holds intent and decisions. Code and tests show what the system actually does. Neither one wins by default.

If you are a human and you do not use AI, ignore this file. Read `README.md` and `CONTRIBUTING.md` instead.
